# 손금은 이미 알고 있다.

수상학으로 찾는 나의 굿즈. 손바닥 사진 한 장으로 손금과 손 모양을 읽어 어울리는 자동차를 4컷 만화와 함께 알려주고, 시계, 복장 스타일, 퍼스널컬러, 음식, 장보는 곳, 컴퓨터 부품, 대형가전, 어울리는 사람, 사는 곳까지 함께 추천하는 웹 게임입니다.

## 진행 순서

1. 시작 → 손(왼손/오른손), 성별(남자/여자/모름), 나잇대를 고릅니다.
2. 촬영 화면에 들어오면 화면 안 카메라가 바로 켜지고, 그 위에 **손바닥만** 들어가는 틀이 보입니다(손가락은 화면 밖이어도 됩니다). 손바닥을 쫙 펴서 틀에 채우면 틀이 초록색으로 바뀌고, 셔터를 누릅니다.
3. 셔터를 누르면 그 자리에서 손바닥을 판별합니다. 잘 찍혔으면 "손바닥이 잘 찍혔어요"라고 알리고 같은 카메라로 손톱 단계로 넘어가고(카메라 권한을 다시 묻지 않음), 아니면 이유를 알려 주고 그 화면에서 다시 찍게 합니다. 이어서 **엄지 손톱** 한 개를 작은 틀에 맞춰 찍습니다. "손톱은 건너뛰기"로 넘어갈 수 있습니다.
4. 손금을 판독합니다. 손바닥이 틀에 맞지 않았거나 손금이 또렷하지 않으면 이유를 알려주고 손바닥만 다시 찍게 합니다(손톱은 다시 찍지 않습니다). 판독 화면에서는 손바닥을 스캔한 뒤 이어서 손톱 사진으로 바뀌어 손톱 테두리 → 모양·빛깔(세로÷가로 비율, 색 견본) → 반달을 차례로 표시합니다. 손톱을 건너뛰었으면 그 단계는 "건너뜀"으로 지나갑니다.
5. 결과 화면 순서: 내 손금 풀이(주요선·보조선·구) → 내 손톱 풀이 → 종합 풀이(성격·연애운·재물운·일과 적성) → **손금이 골라준 당신과 어울리는 굿즈**(자동차·스타일·먹고 사기·전자·PC·대형가전·사람·사는 곳을 같은 급으로, 묶음마다 "왜 이 ○○일까" 설명) → 4컷으로 정리(마지막 컷에 자동차와 다른 굿즈를 함께)
   - 자동차에는 "가격·견적 보러 가기"(다나와자동차), 시계·가전·PC 부품·전자기기·브랜드·음식에는 "다나와 최저가 보기" 같은 버튼이 붙어 다나와 검색 결과로 새 창이 열립니다. 검색어는 `src/js/01b-picks.js` 의 `DANAWA` 에서 만들고, 잘 안 찾아지는 항목은 `FIX` 에 검색어를 직접 적습니다.
6. 결과 이미지를 공유합니다. 지금은 횟수 제한 없이 몇 번이든 다시 할 수 있습니다.

## 사진을 받는 방식

- 화면 안 카메라와 틀은 https 주소(또는 localhost)에서 카메라 권한을 허용했을 때 나옵니다. 권한을 거절했거나 claude.ai 미리보기처럼 카메라를 쓸 수 없는 곳에서는 "카메라로 찍기"(기기의 기본 카메라)와 "앨범에서 고르기" 두 버튼이 나오고, 이때는 틀 없이 사진에서 손바닥을 자동으로 찾습니다.
- 손가락 길이와 엄지 각도("손 모양")는 더 이상 읽지 않습니다. 손바닥 안의 선·구와 엄지 손톱(모양, 손바닥 대비 빛깔, 반달)만 봅니다. 손톱 판독은 합성 그림으로만 맞춘 것이라 실제 사진에서는 정확하지 않을 수 있습니다.
- 화면은 갤럭시 S25 비율(9:19.5, 360×780)에 맞췄습니다. 휴대폰에서는 화면을 가득 채우고, PC에서는 같은 비율의 틀이 가운데에 뜹니다.
- 받은 사진에서 피부색 덩어리를 찾아 손의 크기, 위치, 좌우 방향을 맞춘 뒤 판독합니다. 옆으로 누운 사진은 세워서 읽습니다.
- 자동으로 손을 못 찾은 경우에만, 다시 찍기 화면에 "이 사진에서 직접 맞추기"가 함께 나옵니다. 이때는 찍은 사진 위에 손 모양 틀이 보입니다.

## 들어 있는 파일

| 파일 | 역할 |
| --- | --- |
| `index.html` | 게임 전체. 화면, 손금 판독, 만화 그리기, 공유까지 이 한 파일에 들어 있습니다. |
| `server.js` | 게임을 내려주고, "친구가 실제로 접속했는지"를 확인해 다시 하기 기회를 관리하는 서버. Node.js 18 이상, 설치할 패키지 없음. |

## 실행

```
node server.js
```

브라우저에서 `http://localhost:8787` 을 엽니다. 포트는 `PORT=3000 node server.js` 처럼 바꿉니다.

`index.html` 만 더블클릭해서 열어도 게임은 됩니다. 다만 그때는 서버가 없으므로 "미리보기 모드"로 동작하고, 친구 접속은 집계되지 않습니다.

## 실제로 서비스할 때

1. `index.html` 과 `server.js` 를 같은 폴더에 두고 `node server.js` 를 띄웁니다.
2. **https** 주소로 연결합니다. PC 웹캠은 https(또는 localhost)에서만 열립니다. nginx 같은 프록시 뒤에 둘 때는 `TRUST_PROXY=1 node server.js` 로 실행해야 접속자 IP를 올바르게 봅니다.
3. 기록은 `data.json` 한 파일에 쌓입니다(`DATA_FILE` 환경 변수로 위치 변경). 이용자가 아주 많아지면 DB로 옮기는 것을 권합니다.

## 다시 하기 규칙

> **지금은 꺼져 있습니다.** `CONFIG.GATE_ENABLED` 가 `false` 라서 횟수 제한 없이 누구나 무료로 할 수 있고, 서버도 필요 없습니다. `src/js/01-config.js` 에서 `true` 로 바꾸고 `node build.js` 로 다시 만들면 아래 규칙이 다시 켜집니다(이때는 `server.js` 가 필요).

- 첫 판독은 무료입니다.
- 그다음부터는 내 공유 링크(`?r=코드`)로 **다른 사람이 실제로 접속해야** 기회가 1회 생깁니다.
- 이렇게 얻은 기회는 하루(한국 시간)에 1번만 쓸 수 있습니다. 여러 명이 접속하면 기회는 쌓이고, 하루에 하나씩 쓰게 됩니다.
- 손을 못 찾았거나 손금이 또렷하지 않아 다시 찍는 경우에는 기회가 줄지 않습니다.

규칙 값은 두 곳에 있습니다. 바꿀 때는 둘을 같게 맞춰 주세요.

- `index.html` 의 `CONFIG` (`FIRST_PLAY_FREE`, `DAILY_BONUS_LIMIT`)
- `server.js` 의 `CFG` (같은 이름, 그리고 `MAX_VISITS_PER_IP` 등)

## 손금을 읽는 방법

1. 사진에서 손바닥을 찾고, 밝기는 충분한지, 손과 배경이 구분되는지 확인합니다.
2. 손바닥 영역의 조명을 고르게 편 뒤, 어두운 골(주름)을 찾는 필터를 겁니다.
3. 주요선 넷(생명선·감정선·두뇌선·운명선)이 지나는 구역마다 가장 또렷하게 이어지는 선을 찾아 길이, 깊이, 휘어짐, 끊김을 잽니다. 주요선이 둘 이상 또렷하지 않으면 다시 찍게 합니다.
4. 이어서 더 읽습니다.
   - 보조선: 태양선, 수성선(사업선·건강선), 이중 생명선(화성선), 결혼선, 여행선, 재물선
   - 특별한 손금: M자 손금, 막쥔손금
   - 구(丘): 목성구·토성구·태양구·수성구·금성구·월구. 볼록함은 사진으로 잴 수 없어, 주변보다 붉은 기가 도는 정도(혈색)로 가늠합니다.
   - 손 모양: 손가락 길이, 엄지 각도, 검지와 약지의 길이 차이
5. 측정값을 여섯 성향(활력·모험·감성·이성·상상·뚝심)으로 바꿉니다. 예: 생명선이 크게 휘면 모험, 두뇌선이 곧으면 이성, 태양선이 있으면 감성과 상상. 결과 화면에는 무엇이 어느 성향 점수를 더했는지 적혀 있습니다.
6. 그 사람에게서 두드러지는 성향과 가장 닮은 자동차와 굿즈를 고릅니다.

사진은 기기 안에서만 분석하며 서버로 보내지 않습니다. 성별과 나잇대도 기기에만 저장합니다. 서버가 받는 것은 브라우저가 만든 임의의 ID뿐입니다.

## 내용 바꾸기

- 제목과 규칙: `index.html` 의 `CONFIG`.
- 자동차 목록과 문구: `CARS`. 차마다 이름, 한 줄 소개, 만화 대사, 성향 점수가 있습니다. 출시·단종 상황에 맞게 운영 전에 한 번 확인해 주세요.
- 자동차 외 추천: `PICKS`. 항목(시계, CPU, TV …)마다 후보가 있고, 후보마다 어떤 성향과 맞는지(`w`)와 이유 문구가 있습니다. 후보를 더하거나 빼도 됩니다.
  - 제품은 "제조사 · 브랜드 · 제품군"으로 적었습니다. 2026년 11월에 CPU, TV, 세탁건조기, 김치냉장고의 제품군 이름은 검색으로 확인했고, 나머지(시계, 마우스, 키보드, 케이스, 노트북, 모니터 등)는 확인하지 못했습니다. 운영 전에 판매 중인지 확인해 주세요.
  - `PICK_LENS`: 항목마다 가장 두드러진 성향으로 고를지, 두 번째·세 번째 성향으로 고를지 정합니다.
  - `TRAIT_BASE`: 보통 손금에서 나오는 성향별 평균 점수(모의 실험값). 실제 이용자 데이터가 쌓이면 그 평균으로 바꿔 주세요.
- 퍼스널컬러: 찍힌 손바닥 피부의 밝기와 노란 기로 네 계절 중 하나를 고릅니다(`PERSONAL_COLORS`). 조명의 영향을 받습니다.
- 어울리는 사람: `PARTNER`. 가장 낮은 성향을 채워 주는 타입과 인상, 널리 알려진 MBTI 궁합표를 씁니다. 10대를 고르면 "이성" 대신 "친구"로 바꿔 보여 줍니다.
- 사는 곳: `PICKS.region`. 대한민국 시·도와 도시, 해외 도시, 북한 도시가 한 목록에 있습니다.
- 구의 이름과 뜻: `MOUNT_INFO`. 보조선·손 모양의 풀이 문구: "04. 수상학 해석" 부분의 `reading`.
- 다시 찍기 안내 문구: `RETAKE`.
- 자동차 그림은 차종(세단, SUV, 픽업 등)을 나타내는 일반적인 만화체입니다. 실제 모델의 디자인이나 로고는 넣지 않았습니다.

## 알아둘 점

- 판독 기준값은 합성한 손바닥 이미지로 맞췄습니다. 실제 사진으로는 아직 확인하지 못했습니다. 여러 사람의 손으로 찍어 보고 너무 자주 다시 찍으라고 하거나 너무 쉽게 통과시키면 `index.html` 의 "03. 손금 판독 엔진" 부분에서 기준값(`inside`, `fingers`, `outside`, `thr`)을 조정해 주세요.
- 사진에서 손을 찾는 부분(`autoFit`)과 보조선·구·손 모양 판독도 합성 이미지에서만 확인했습니다. 보조선은 가늘어서 실제 사진에서는 못 읽거나 잔주름을 선으로 읽을 수 있습니다.
- 손과 비슷한 색의 배경(나무 책상, 베이지색 벽) 앞에서는 손을 못 찾을 수 있습니다. 그때는 다시 찍기 안내와 "직접 맞추기"가 나옵니다.
- 친구 접속은 브라우저 단위로 셉니다. 같은 사람이 다른 브라우저나 시크릿 창으로 접속하면 친구로 집계될 수 있습니다. 같은 IP에서 같은 링크로 인정되는 접속은 하루 5번으로 막아 두었습니다(`MAX_VISITS_PER_IP`).
- 재미로 보는 손금입니다.
